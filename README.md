## 프로젝트 개요

K-패스 웹사이트 리디자인은 교통비 지원 서비스의 정보를 사용자가 더 쉽고 빠르게 이해할 수 있도록 개선한 프로젝트입니다.

기존 사이트의 복잡한 정보 구조와 약한 CTA 흐름을 보완하고,  
서비스 혜택 → 이용 절차 → 카드 발급 → 공지/이벤트 확인으로 이어지는 사용자 흐름을 중심으로 메인 페이지를 재구성했습니다.

사용자가 필요한 정보를 헤매지 않고 확인할 수 있도록 섹션을 명확히 나누고,  
반응형 웹 구현을 통해 다양한 화면에서도 안정적으로 이용할 수 있는 웹페이지를 목표로 했습니다.
